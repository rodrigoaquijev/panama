# Panamá · Luna de miel (25–30 nov 2026)

Web-app estática (sin build): `index.html` + `img/` (fotos de Wikimedia Commons con licencia libre, créditos dentro de la app) + `sw.js` (funciona sin señal) + `manifest.webmanifest` (se puede "Agregar a pantalla de inicio").

## Publicar en Vercel

```bash
npx vercel --prod
```

Framework: **Other**. Build command y output directory vacíos. O arrastrar esta carpeta en vercel.com → Add New → Project.

## En el celular
- Abrir el enlace → menú del navegador → **Agregar a pantalla de inicio**: queda como app y guarda fotos y plan para usar sin internet (el mapa necesita conexión).
- El checklist, presupuesto y tema se guardan en cada celular.
- Durante el viaje, la app abre directo en el día de hoy.
